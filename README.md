# Chasha'Miam — maquette validée + menu intégré

Cette version repart strictement de la base validée et y intègre la carte restructurée.

- palette, typographies, navigation et mise en page conservées ;
- logo et illustrations principales conservés ;
- contenu de carte géré dans `script.js` ;
- Gourmandises garde ses quatre sous-catégories ;
- correction : **Le Joufflu** ;
- Macarons Mignons, Mini-Cookies et Mini-Meringues sont dans Gâteaux de voyage ;
- Onctueux Baos et Plateau Thavnaïrois sont dans Salé.
